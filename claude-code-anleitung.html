1
Installation & Setup
Einmalig — dauert ca. 10 Minuten
🧰 Was du brauchst
  • ✓Claude mit Claude Code aktiviert (claude.ai → Settings → Features)
  • ✓Git installiert → git-scm.com/download
  • ✓Node.js 20+ → nodejs.org
  • ✓Terminal — Windows: PowerShell / CMD · Mac: Terminal
💡 Prüfen ob Node installiert ist: node --version im Terminal — zeigt z.B. v20.11.0
Terminal — Projektordner erstellen
# Windows PowerShell mkdir C:\MeineProjekte cd C:\MeineProjekte # Mac / Linux mkdir ~/MeineProjekte cd ~/MeineProjekte
🔧 Claude Code aktivieren
  1. Claude öffnen (App oder Browser)
  2. Settings öffnen → Features
  3. Claude Code → einschalten
  4. Claude neu starten — fertig
2
Erstes Projekt starten
Einfach Claude einen klaren Prompt geben
📋 Beispiel-Prompt für Claude
Erstelle mir ein Next.js Projekt mit TypeScript und Tailwind CSS. Der Name soll "mein-app" sein. Führe alle Setup-Befehle aus und starte den Dev-Server.
⚡ Was Claude dann automatisch macht
  • Projekt-Ordner anlegen + Dateien erstellen
  • Dependencies installieren (npm install)
  • Konfigurationen setzen (TypeScript, Tailwind, ESLint)
  • Dev-Server starten → http://localhost:3000
✅ Hot Reload inklusive: Jede Änderung wird sofort im Browser sichtbar — kein manueller Neustart nötig.
3
Remote-Coding in der Praxis
So gibst du Claude klare Aufgaben
📋 Landing Page bauen
Baue mir eine Landing Page mit: - Hero-Section mit Gradient-Hintergrund - 3 Feature-Cards mit Icons - Call-to-Action Button (lila, animiert) - Komplett responsive für Handy Nutze React + Tailwind. Halte alles in einer Datei.
📋 Neue Komponente erstellen
Erstelle eine React-Komponente "Button" in src/components/Button.tsx. Sie soll: - Text als Prop akzeptieren - Varianten haben: primary, secondary, danger - Mit Tailwind gestylt sein - TypeScript Props korrekt typisiert haben
📋 Bug fixen lassen
Meine Navigation klappt auf Handy nicht richtig zusammen. Debugge das Problem in src/components/Navbar.tsx und behebe es.
📋 Dark Mode hinzufügen
Füge einen Dark Mode Toggle hinzu: - Button in der Navbar (Mond/Sonne Icon) - Preference in localStorage speichern - Smooth CSS Transition (300ms) - System-Preference automatisch erkennen
4
Praktische Remote-Befehle
Copy-Paste Prompts für häufige Aufgaben
Datei-Operationen
Dateiinhalt anzeigen lassen
Zeig mir den aktuellen Zustand der Datei: src/pages/index.tsx
Mehrere Dateien auf einmal
Zeig mir alle Dateien im Ordner src/components/ und erkläre was jede macht.
Deployment
Für Vercel vorbereiten
Bereite das Projekt für Vercel vor: - Prüfe ob vercel.json existiert, sonst erstelle sie - Optimiere den Build für Production - Prüfe ob alle Environment Variables dokumentiert sind
Für Render.com (PHP/Docker)
Bereite für Render.com vor: - Dockerfile prüfen / optimieren - render.yaml korrekt konfigurieren - Health-Check Endpoint vorhanden?
Code Review
Security + Performance Review
Review meinen Code auf: - Security-Lücken (XSS, SQL-Injection, CSRF) - Performance-Probleme (unnötige Re-Renders, fehlende Indexes) - Best Practices (TypeScript strict, ESLint Regeln) - Fehlende Error-Handling
5
Mit Git arbeiten
Versionskontrolle & Backup — Claude macht alles per CLI
📋 Git initialisieren + erster Push
Initialisiere Git in diesem Projekt, erstelle einen ersten Commit mit sinnvoller Message, und push es zu meinem GitHub Repo: https://github.com/DEIN-USERNAME/DEIN-REPO
Was Claude dann ausführt
# Claude führt diese Befehle automatisch aus: git init git add . git commit -m "feat: initial project setup" git remote add origin https://github.com/user/repo.git git push -u origin main
⚠️ Tipp: Nie Passwörter oder API-Keys in Git committen. Claude erkennt das und warnt dich — aber prüfe immer selbst ob .env in der .gitignore steht.
🔄 Nützliche Git-Prompts
  • ✓„Erstelle einen Feature-Branch für die neue Login-Seite"
  • ✓„Was hat sich seit dem letzten Commit geändert?"
  • ✓„Merge den feature-branch in main mit einem sauberen Commit"
  • ✓„Erstelle einen Pull Request für diesen Branch auf GitHub"

Tipps & Tricks
So holst du das Maximum raus
🎯
Sei spezifisch
Nicht "mach ne Website" — sondern "Erstelle ein Portfolio mit Projekt-Galerie, Dark Mode und Contact-Form"
🧱
Stack vorgeben
Immer sagen was du willst: "nutze React + Tailwind" oder "PHP 8.2 + SQLite, kein Framework"
🎨
Stil beschreiben
"Soll modern und minimalistisch wirken, dunkles Theme, Lila-Akzente" — Claude versteht Ästhetik
🔁
Iterieren
Erstmal grob bauen lassen, dann verfeinern: "Der Button soll größer sein und einen Hover-Effekt haben"
📁
Kontext geben
"Zeig mir erst src/pages/index.tsx — dann füge die neue Sektion ein" — Claude liest erst, dann handelt
🛑
Server stoppen
Im Terminal Ctrl + C — stoppt den laufenden Dev-Server sofort
🚀 Pro-Tipp: Nutze "Council this:" wenn du eine wichtige Tech-Entscheidung treffen musst (z.B. React vs. Next.js). Claude ruft dann 5 unabhängige Advisor auf und gibt dir ein strukturiertes Verdict.

Häufige Probleme & Lösungen
Was tun wenn's nicht klappt
❌ "node: command not found"

Node.js ist nicht installiert oder nicht im PATH.

# Node.js herunterladen von: https://nodejs.org/ # LTS Version wählen # Nach Installation: Terminal neu starten node --version # sollte v20.x.x zeigen
❌ Port 3000 already in use

Ein anderer Prozess belegt den Port.

# Windows — Prozess auf Port 3000 finden + killen: netstat -ano | findstr :3000 taskkill /PID [PID-NUMMER] /F # Oder einfach anderen Port nutzen: npm run dev -- --port 3001
❌ Git Push schlägt fehl
# GitHub Authentication einrichten: git config --global user.email "deine@email.de" git config --global user.name "Dein Name" # Personal Access Token auf GitHub erstellen: # github.com → Settings → Developer Settings → Tokens # Token als Passwort beim ersten Push eingeben
❌ Claude macht nicht was ich will
  • Prompt präzisieren: Dateinamen + Technologie explizit nennen
  • "Zeig mir erst die aktuelle Datei" — dann Änderungen anfordern
  • Einen Schritt nach dem anderen — nicht 5 Features gleichzeitig
  • Bei Fehlern: Fehlermeldung komplett in den Chat kopieren
